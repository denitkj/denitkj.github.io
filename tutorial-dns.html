BIND9 Docs

Konfigurasi DNS Server Manual

Panduan mendalam menggunakan editor nano untuk mengonfigurasi BIND9 di Debian.

1

Instalasi Paket Utama

Pastikan server terhubung ke internet untuk mengunduh paket Bind9 dan DNS Utilities.

apt update && apt install bind9 dnsutils -y
2

Salin Template Zone

Kita tidak membuat file dari nol, melainkan menyalin dari template yang sudah disediakan Bind9.

cd /etc/bind
cp db.local db.forward
cp db.127 db.reverse
3

Edit Forward Zone

Mengatur pemetaan nama domain ke alamat IP.

Gunakan perintah: nano db.forward 
$TTL 604800
@   IN  SOA deni.local. root.deni.local. (
              2         ; Serial
         604800         ; Refresh
          86400         ; Retry
        2419200         ; Expire
         604800 )       ; Negative Cache TTL
;
@   IN  NS  deni.local.
@   IN  A   192.168.4.20
www IN  A   192.168.4.20
4

Edit Reverse Zone

Mengatur pemetaan alamat IP kembali ke nama domain.

Gunakan perintah: nano db.reverse 
$TTL 604800
@   IN  SOA deni.local. root.deni.local. (
              1         ; Serial
         604800         ; Refresh
          86400         ; Retry
        2419200         ; Expire
         604800 )       ; Negative Cache TTL
;
@   IN  NS  deni.local.
20  IN  PTR deni.local.
5

Daftarkan Zone Baru

Memberitahu Bind9 di mana lokasi file database yang telah kita buat.

Gunakan perintah: nano named.conf.default-zones 
zone "deni.local" {
    type master;
    file "/etc/bind/db.forward";
};

zone "4.168.192.in-addr.arpa" {
    type master;
    file "/etc/bind/db.reverse";
};

Jangan lupa restart bind9: systemctl restart bind9

6

Konfigurasi DNS Resolver

Daftarkan IP server Anda ke sistem agar dapat mengenali domain lokal.

Gunakan perintah: nano /etc/resolv.conf 
nameserver 192.168.4.20
7

Uji Coba (Testing)

Gunakan perintah nslookup untuk memverifikasi apakah DNS sudah menjawab dengan benar.

A. Cek Domain Utama 
nslookup deni.local
Contoh Output Berhasil
Server:  192.168.4.20
Address: 192.168.4.20#53

Name:    deni.local
Address: 192.168.4.20
B. Cek Subdomain (WWW) 
nslookup www.deni.local
Contoh Output Berhasil
Server:  192.168.4.20
Address: 192.168.4.20#53

Name:    www.deni.local
Address: 192.168.4.20
