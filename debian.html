Debian 11.7.0

Apa itu Repositori?

Repositori adalah server pusat tempat ribuan paket aplikasi Debian disimpan. Ini memungkinkan sistem operasi untuk mengunduh dan menginstal perangkat lunak secara otomatis melalui perintah apt.

"Repositori Debian 11 menggunakan kode nama Bullseye."

Perintah Dasar

Update Daftar Paket

sudo apt update

Upgrade Sistem

sudo apt upgrade

Instal Aplikasi

sudo apt install [nama]

Edit File Repositori

nano /etc/apt/sources.list
/etc/apt/sources.list

Tips: Gunakan repositori lokal (Indonesia) agar kecepatan download lebih maksimal saat melakukan update atau instalasi paket di server Anda.
